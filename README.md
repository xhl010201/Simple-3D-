# Simple 3D 汉化版

> 一个将官方扩展 [Simple 3D](https://extensions.turbowarp.org/Xeltalliv/simple3D) 汉化的版本，仅修改显示文本，不改任何代码逻辑。

## 简介

[Simple 3D](https://extensions.turbowarp.org/Xeltalliv/simple3D) 是 Turbowarp 上一款强大的 3D 渲染扩展，但原版全部为英文。

本仓库提供其**汉化版**，方便中文用户使用。

## 特点

- 仅修改「积木显示文本」，不涉及任何变量名、函数名、属性名
- 代码逻辑与原版完全一致，功能不受影响
- 积木加载后直接显示为中文

## 使用方法

1. 下载 `Simple3D-汉化版.js`
2. 打开 Turbowarp 编辑器
3. 进入 `扩展` → `加载自定义扩展` → `从文件加载`
4. 选择下载好的 `.js` 文件
5. 积木即显示为中文

> 若已加载过原版 Simple 3D，请先移除原版，再加载汉化版。
> （二者 ID 相同，无法共存）

## 兼容性

- 基于 Simple 3D 版本 **1.3.0**
- 汉化内容：112 条积木文本 + 菜单选项
- 与原版 API 完全一致
